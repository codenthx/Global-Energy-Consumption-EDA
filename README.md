# 🌍 Global Energy Consumption Analysis using Python

A complete Exploratory Data Analysis (EDA) project performed on a real-world Global Energy Consumption dataset using Python and Google Colab.

---

## 📌 Project Overview

This project explores historical global energy consumption data to identify trends, clean missing values, detect outliers, and visualize important patterns.

The objective was to perform a complete EDA workflow suitable for data analysis and future machine learning applications.

---

## 🎯 Objectives

- Explore and understand the dataset
- Handle missing values
- Remove duplicate records
- Generate statistical summaries
- Detect outliers
- Create meaningful visualizations
- Export a cleaned dataset

---

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📊 Visualizations

This project includes:

- Distribution of records by year
- Top countries in the dataset
- Population distribution
- Population boxplot (Outlier Detection)
- Correlation heatmap
- Average population over time
- Top 10 countries by average population
- Countries recorded per year
- Population distribution histogram

## Key Insights

- The dataset contains energy-related information from multiple countries over several decades.
- Missing values and duplicate records were successfully handled.
- Population data is highly skewed due to a few countries with exceptionally large populations.
- Correlation analysis revealed relationships between numerical variables.
- The dataset provides a strong foundation for future machine learning and predictive analytics projects.
